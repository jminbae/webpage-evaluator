🏗️ 1. 구조화 데이터(Schema) 검증

3 도구

검색 엔진과 AI가 페이지 콘텐츠를 이해하도록 돕는 JSON-LD 마크업 검증. 두 도구를 같이 돌리는 게 정석이에요.

Google Rich Results Test

무료필수

search.google.com/test/rich-results

Google이 페이지의 구조화 데이터로 어떤 리치 결과를 보여줄지 검증. 검색 결과 미리보기까지 가능.

무엇을 봐야 하나
  • 리치 결과 적격 여부 (예: FAQ, Article, Product)
  • 경고/에러 항목 (필수 필드 누락)
  • 모바일 미리보기 확인

Google이 지원하는 타입만 검증 — Person/MedicalOrganization 등은 코멘트가 없을 수 있음.

Schema.org Markup Validator

무료필수

validator.schema.org

schema.org 800+ 타입 전체 검증. JSON-LD/RDFa/Microdata 문법 오류 식별 + 그래프 요약.

무엇을 봐야 하나
  • 모든 타입의 필수 속성 충족 여부
  • 참조(@id) 연결이 끊어지지 않았는지
  • 에러(빨강) → 경고(노랑) 순으로 해결

Google 미지원 타입까지 검증 — Person/Physician 등 의료 스키마는 여기가 더 정확.

Classy Schema Viewer

무료

classyschema.org/Visualisation

엔티티 관계를 인터랙티브 그래프로 시각화. JS 렌더링 후 동적 콘텐츠도 잡음.

무엇을 봐야 하나
  • 엔티티 간 관계가 의도대로 연결됐는지
  • 고립된 노드(연결 없는 스키마) 없는지
  • 데이터 모델 디버깅

복잡한 데이터 구조(원장-클리닉-Q&A 등) 디버깅에 최적.

🔍 2. SEO 기본 — 검색엔진 등록·관리

3 도구

한국 시장이면 Google + Naver 둘 다 필수 등록. 데이터가 누적되니 빨리 등록할수록 이득.

Google Search Console

무료필수

search.google.com/search-console

Google 검색 트래픽·실적 측정, URL 검사, 색인 상태 확인. SEO의 시작점.

무엇을 봐야 하나
  • 사이트맵 제출 (sitemap.xml)
  • 색인 생성 여부 (URL 검사)
  • Core Web Vitals 리포트
  • 구조화 데이터 오류 리포트
  • 검색어별 노출·CTR

Naver Search Advisor

무료필수

searchadvisor.naver.com

네이버 검색 노출/클릭, 사이트 진단, RSS·사이트맵 제출. 한국 트래픽 절반 이상이 네이버.

무엇을 봐야 하나
  • 색인 URL 수 / 수집제한 / 색인제외
  • SEO 이슈 URL 리포트
  • RSS 제출 (필수)
  • 웹마스터 도구의 robots.txt 검증

의료 콘텐츠·로컬 비즈니스면 Google보다 네이버 가중치가 높음.

Bing Webmaster Tools

무료

bing.com/webmasters

Bing 색인 등록. ChatGPT가 Bing 인덱스를 쓰던 시절 흔적이 있어 AEO에 약간 도움.

무엇을 봐야 하나
  • 등록만 해두면 충분 (5분)
  • 가끔 사이트맵 재제출

⚡ 3. 페이지 속도·Core Web Vitals

2 도구

모바일 성능은 SEO 점수에 직결. 이미지 크기·LCP·CLS·INP가 핵심.

Google PageSpeed Insights

무료필수

pagespeed.web.dev

URL 입력 → 모바일/데스크탑 점수, LCP·FID·CLS·INP 진단.

무엇을 봐야 하나
  • 모바일 점수 (특히)
  • LCP < 2.5s, INP < 200ms, CLS < 0.1
  • 이미지 최적화 권고 (WebP, lazy load)
  • JavaScript 차단 시간

Chrome DevTools — Lighthouse

브라우저 내장필수

F12 → Lighthouse 탭 → Generate Report

PSI와 같은 엔진. Performance·Accessibility·SEO·Best Practices·PWA 5개 카테고리 한 번에.

무엇을 봐야 하나
  • Performance, SEO, Accessibility 90+ 목표
  • PWA 점수 (PWA 사이트라면)
  • 실제 디바이스 시뮬레이션

📝 10. AEO 필수 파일 점검

2 항목

AEO/GEO 도구들이 공통으로 짚는 두 파일. 사이트 루트에 직접 호스팅.

robots.txt — AI 크롤러 허용 여부

필수

{도메인}/robots.txt

GPTBot, ClaudeBot, PerplexityBot, Google-Extended가 차단되면 AI 인용 불가.

점검 — Disallow: / 가 걸려 있으면 안 됨
  • GPTBot (OpenAI)
  • ClaudeBot, anthropic-ai (Anthropic)
  • PerplexityBot (Perplexity)
  • Google-Extended (Gemini)
  • cohere-ai, CCBot

차단 의도가 없으면 명시적으로 User-agent: GPTBot Allow: / 추가.

llms.txt — AI용 사이트 요약

권고

{도메인}/llms.txt

사이트 루트에 마크다운 형식으로 "AI가 사이트를 이해하기 쉽게" 정리.

기본 형식
  • # 사이트명 + 한 줄 소개
  • ## 주요 카테고리 + 대표 URL 목록
  • ## 연락처·정책 링크

현재 권고 수준이지만 Anthropic·OpenAI가 점차 참고하는 방향.

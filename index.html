웹페이지 분석 도구 카탈로그

한 번의 URL 입력 → 모든 외부 도구로 자동 전달 + 즉시 자동 점검. LLM 없이 결정적 metric만 출력. 무료(또는 freemium 핵심 기능 무료) 도구만 모았어요.

🧩 크롬 확장 NEW · 더 강력

웹 버전의 한계(CORS 프록시 의존, JS 렌더링 전 HTML만 분석)를 해결한 크롬 확장 버전. 현재 보고 있는 페이지에서 아이콘 클릭 한 번으로 즉시 분석.

✓ CORS 우회
공용 프록시 불필요. 어떤 사이트든 직접 fetch.
✓ 렌더링 후 DOM
JS 실행 후 실제 DOM 분석 (SPA·CSR 사이트도 정확).
✓ URL 입력 불필요
현재 탭 자동 인식. 아이콘 클릭만.
+ 키워드 제안
Google Suggest + Naver 자동완성 + Wayback 아카이브.
📦 설치 방법 (개발자 모드 sideload, 무료)
  1. 이 GitHub 레포에서 extension/ 폴더를 다운로드 (또는 전체 ZIP 다운로드 후 압축 해제)
    → GitHub 레포 열기
  2. Chrome 주소창에 chrome://extensions/ 입력
  3. 우상단 "개발자 모드" ON
  4. "압축해제된 확장 프로그램을 로드합니다" 클릭
  5. extension/ 폴더 선택
  6. 도구모음의 퍼즐 아이콘 → "웹페이지 분석 도구" 핀 고정 권장
  7. (선택) 확장 옵션에서 PageSpeed Insights API 키 입력 → Core Web Vitals 자동 측정

⚠ Chrome Web Store 게시 전이라 sideload만 가능합니다 (개발자 등록 $5 결제 후 게시 예정). 이 방식은 무료고 안전합니다.

📍 검사할 URL을 한 번만 입력하세요
URL을 입력하면 모든 외부 도구 링크가 자동으로 그 URL을 전달하도록 갱신됩니다.
⚙️ 고급 설정 (PageSpeed API 키 / CORS 프록시)
⚠ 공용 프록시는 가끔 다운될 수 있어요. 실패시 다른 걸로 변경하세요.

🚀 즉시 자동 분석 METRIC ONLY · LLM-FREE

위에 URL 입력 후 "즉시 분석" 클릭. 외부 도구를 안 거치고 브라우저에서 직접 결정적 점검 수행.

🏗️ 1. 구조화 데이터(Schema) 검증

3 도구

검색 엔진과 AI가 페이지 콘텐츠를 이해하도록 돕는 JSON-LD 마크업 검증.

Google Rich Results Test

무료필수URL 자동

search.google.com/test/rich-results

Google이 페이지의 구조화 데이터로 어떤 리치 결과를 보여줄지 검증.

무엇을 봐야 하나
  • 리치 결과 적격 여부
  • 경고/에러 항목
  • 모바일 미리보기
도구 열기

Schema.org Markup Validator

무료필수URL 자동

validator.schema.org

schema.org 800+ 타입 전체 검증. JSON-LD/RDFa/Microdata.

무엇을 봐야 하나
  • 모든 타입의 필수 속성 충족 여부
  • 참조(@id) 연결
  • 에러 → 경고 순으로 해결
도구 열기

Classy Schema Viewer

무료

classyschema.org/Visualisation

엔티티 관계를 인터랙티브 그래프로 시각화. JS 렌더링 후 동적 콘텐츠도 잡음.

무엇을 봐야 하나
  • 엔티티 간 관계가 의도대로 연결됐는지
  • 고립된 노드(연결 없는 스키마) 없는지

⚡ 3. 페이지 속도·Core Web Vitals

2 도구

모바일 성능은 SEO 점수에 직결. LCP/CLS/INP가 핵심.

Google PageSpeed Insights

무료필수URL 자동

pagespeed.web.dev

URL 입력 → 모바일/데스크탑 점수, LCP·FID·CLS·INP 진단.

기준
  • LCP < 2.5s, INP < 200ms, CLS < 0.1
  • 모바일 점수 ≥ 90 권장
  • 이미지 최적화 (WebP, lazy load)
도구 열기

Chrome DevTools — Lighthouse

브라우저 내장필수

F12 → Lighthouse 탭 → Generate Report

PSI와 같은 엔진. Performance·Accessibility·SEO·Best Practices·PWA 5개 카테고리.

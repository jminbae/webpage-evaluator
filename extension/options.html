🔑 PageSpeed Insights API 키

Google PSI API 키를 입력하면 Core Web Vitals(LCP/CLS/INP) 자동 측정. 키 없이도 다른 모든 점검은 작동.

🔗 키 발급 문서 (Google)
→ Google Cloud Console에서 API 활성화 → 키 생성 → 여기 붙여넣기. 무료 한도 하루 25,000회.

📋 점검 항목 (참고)

HTML 분석: schema(JSON-LD), meta·OG·Twitter, canonical, hreflang, viewport, headings, images alt, internal/external links, FAQ schema, E-E-A-T signals, RSS, lang
외부 fetch: /robots.txt(AI 봇 12개 차단 여부), /llms.txt(존재·형식), /sitemap.xml(URL 수)
아카이브: Wayback Machine 첫 스냅샷·총 스냅샷 수
키워드 제안: Google Suggest, Naver 자동완성
PSI(선택): Mobile + Desktop Performance 점수, LCP, CLS, INP

🔒 프라이버시

이 확장은 외부 서버로 데이터를 전송하지 않습니다 (LLM API 미사용). PSI API 키는 chrome.storage.sync에 본인 계정에만 저장. 모든 분석은 다음 공개 API만 호출:
• Google PageSpeed Insights API (사용자 키)
• Google Suggest (suggestqueries.google.com)
• Naver 자동완성 (ac.search.naver.com)
• Wayback Machine (archive.org)
• 분석 대상 사이트의 /robots.txt, /llms.txt, /sitemap.xml
